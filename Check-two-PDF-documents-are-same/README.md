# Purpose:
This repository contains a Python script that allows you to check if two PDF documents are identical. The script takes two file paths as arguments and compares the hashes of the files. If the hashes are the same, it means that the files are identical.

# What we want to achieve:
We want to be able to quickly and easily check if two PDF documents are identical using Python. This can be useful in various scenarios, such as verifying the integrity of downloaded files or comparing versions of a document.
